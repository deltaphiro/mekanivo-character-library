# MEKANIVO Character Library

Repository untuk aset karakter MEKANIVO yang reusable: source, rig, animasi, referensi, preview, dan catatan QC.

## Struktur
- `characters/`: paket per karakter.
- `standards/`: format aset dan standar QC.
- `templates/`: template karakter baru.
- `tests/`: checklist testing.
- `library-index.json`: indeks/status library.

## Status karakter
- **Ucup v0.3.0-draft** — tersedia untuk review; belum di-approve atau diuji di runtime MEKANIVO Motion, jadi belum production-ready.
- Karakter lain/template — scaffold awal.

## Cara pakai
Baca README dan `manifest.json` karakter terlebih dahulu. Gunakan source versi draft sebagai bahan eksperimen, bukan aset production, sampai compatibility dan render test di Motion terverifikasi.
