# Character package template

Buat paket berdasarkan anatomi karakter dan kemampuan runtime.

File yang mungkin diperlukan:
- character.js: entry point (jika runtime memakai JavaScript).
- geometry.js: vector geometry/parts.
- rig.js: pivot, hierarchy, transform.
- behaviors.js: action khusus karakter.
- expressions.js: ekspresi wajah jika relevan.
- preview.png: thumbnail.
- manifest.json: identitas, capability, versi, status QC.

Ini contoh organisasi, bukan paksaan. Tetapkan format final setelah inspect Motion 2.9.2.
