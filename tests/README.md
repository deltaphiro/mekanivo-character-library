# Character Test Pack

Jalankan test setelah source terintegrasi dengan renderer Motion 2.9.2:
1. Idle / subtle motion.
2. Core articulation atau segment movement.
3. Action-to-idle transition.
4. Extreme pose dan silhouette stress test.
5. Camera zoom/pan independence.
6. Normal playback check: stiffness, jitter, gap, clipping.

Catat hasil dan render preview. Jangan tandai production-ready hanya karena kode berhasil dieksekusi.
